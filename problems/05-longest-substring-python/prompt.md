# Longest Substring Without Repeating Characters

## Problem

Given a string `s`, return the length of the longest substring that does not
contain any repeated character.

A substring is a contiguous part of the string.

## Examples

Input:  `"abcabcbb"`
Output: `3` (the substring `"abc"`)

Input:  `"bbbbb"`
Output: `1` (the substring `"b"`)

Input:  `"pwwkew"`
Output: `3` (the substring `"wke"`)

Input:  `""`
Output: `0`

## Constraints

- `0 <= s.length <= 5 * 10**4`
- `s` may contain letters, digits, symbols and spaces.
